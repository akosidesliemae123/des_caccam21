## Mission Overview

In this laboratory, I will explore and compare three major public cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

The purpose of this activity is to understand the major cloud services offered by each provider, compare their strengths, and determine which cloud platform is appropriate for different business requirements.

## Linux Investigation

A Linux environment will be investigated using the KillerCoda Playground.

The investigation will identify:

* Operating System
* CPU Information
* Memory
* Disk Space

The Linux server will then be mapped to possible cloud services from AWS, Microsoft Azure, and GCP.

### Linux-to-Cloud Mapping

A Linux server can be hosted using virtual machine services such as:

* AWS EC2
* Microsoft Azure Virtual Machines
* Google Compute Engine

These services provide virtual computing environments where Linux-based applications and servers can run in the cloud.
