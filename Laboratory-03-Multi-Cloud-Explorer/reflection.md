# Mission Reflection

## Laboratory 03 – Multi-Cloud Explorer

This laboratory helped me understand the differences between AWS, Microsoft Azure, and Google Cloud Platform. Among the three platforms, AWS impressed me the most because of its wide range of cloud services and its ability to support different types of organizations and workloads. I learned that AWS provides many options for computing, storage, networking, databases, security, and other cloud requirements.

AWS, Azure, and Google Cloud have many similarities because all three provide essential cloud computing services such as virtual machines, object storage, networking, identity management, databases, and Kubernetes. They also provide global infrastructure that allows organizations to deploy applications and services in different geographic locations. However, each provider has different strengths, service names, tools, and features that can make one platform more suitable for a particular organization.

Business requirements have a major influence on cloud platform selection. An organization should consider its budget, existing technology, workload, security requirements, scalability, geographic needs, and future growth. For example, Microsoft Azure is a strong choice for an organization that already uses Microsoft technologies, while Google Cloud can be an excellent choice for AI, machine learning, and Kubernetes workloads.

Acting as a Cloud Solutions Consultant helped me understand that selecting a cloud provider is not simply about choosing the most popular platform. A consultant needs to analyze the client's actual requirements and match those requirements with appropriate cloud services. This activity also helped me understand how different cloud services can work together to create complete solutions.

Finally, this laboratory improved my GitHub portfolio by allowing me to organize technical research, comparisons, recommendations, and evidence in a structured way. Using Markdown files and meaningful commits makes the portfolio easier to understand and demonstrates my progress in learning cloud computing. It also gave me practical experience documenting technical information in a professional format.
